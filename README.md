# make-knowledge-cards

`make-knowledge-cards` 是一个 Codex Skill，用于把用户粘贴的文章，或本地 Markdown/TXT 文件，转换成 5-8 张中文版知识卡片。

它适合整理学习材料、文章笔记、课程阅读材料和知识型文本。Skill 会优先提取真正重要的知识点，删除重复内容，并避免编造原文没有的信息。若原文信息不足，它会输出少于 5 张卡片，而不是强行凑数量。

## 1. 项目解决什么问题

很多文章内容较长、重复信息较多，直接阅读后不容易形成可复习的知识结构。本项目解决的是：

- 从文章中提取真正重要的知识点。
- 把长文本整理成结构统一、便于复习的知识卡片。
- 避免把同一个观点重复拆成多张卡片。
- 避免加入原文没有的信息。
- 在内容不足时，避免为了达到数量要求而生成空泛卡片。

## 2. 主要功能

- 支持用户直接粘贴文章文本。
- 支持读取本地 `.md`、`.markdown`、`.txt` 文件。
- 输出 5-8 张知识卡片；如果原文不足以支持 5 张，则输出更少卡片并说明原因。
- 每张卡片包含：
  - 标题
  - 核心知识
  - 简明解释
  - 例子或自测问题
- 一张卡片只讲一个知识点。
- 自动合并重复或高度相似的内容。
- 优先使用原文中的例子；没有例子时生成自测问题。

当前不支持：

- 网页抓取
- PDF 处理
- Anki 导出
- 图形界面

## 3. 安装方法

将本仓库中的 Skill 目录放到 Codex 可读取的位置即可使用。当前项目结构为：

```text
skills/
  make-knowledge-cards/
    SKILL.md
    agents/
      openai.yaml
```

如果你要安装到自己的 Codex Skills 目录，可以复制整个目录：

```bash
cp -R skills/make-knowledge-cards ~/.codex/skills/
```

安装后，重启或刷新 Codex，让它重新发现 Skill。

## 4. 使用方法

### 方式一：粘贴文章

```text
Use $make-knowledge-cards to convert this article into Chinese knowledge cards:

这里粘贴文章正文……
```

也可以直接用中文提问：

```text
请使用 $make-knowledge-cards，把下面这篇文章整理成中文版知识卡片：

这里粘贴文章正文……
```

### 方式二：使用本地 Markdown/TXT 文件

```text
请使用 $make-knowledge-cards 读取 ./notes/article.md，并制作中文版知识卡片。
```

支持的本地文件类型：

- `.md`
- `.markdown`
- `.txt`

## 5. 输入输出示例

### 示例输入

```text
请使用 $make-knowledge-cards，把下面这段文字整理成中文版知识卡片：

检索练习有助于长期学习，因为它要求学习者主动回忆信息，而不是只反复阅读材料。短测验可以暴露学习者已经遗忘的内容。把测验分散在不同时间进行，通常比一次性集中复习更有效。反馈也很重要，因为它能在错误变得熟悉之前及时纠正错误。
```

### 示例输出

```markdown
原文只支持 3 张不编造信息的知识卡片。

1. **标题：主动回忆促进长期记忆**
   **核心知识：** 检索练习比单纯反复阅读更有助于长期学习。
   **简明解释：** 检索练习要求学习者主动从记忆中提取信息，这种主动回忆能帮助巩固知识。
   **例子或自测问题：** 为什么短测验可能比重新读一遍材料更有帮助？

2. **标题：短测验可以发现遗忘内容**
   **核心知识：** 测验能暴露学习者已经遗忘或掌握不牢的内容。
   **简明解释：** 通过测验，学习者可以看到哪些知识没有真正记住，从而更有针对性地复习。
   **例子或自测问题：** 如果一次测验暴露出某个概念已经遗忘，下一步应该如何调整复习？

3. **标题：反馈能及时纠正错误**
   **核心知识：** 反馈可以在错误变得熟悉之前纠正错误。
   **简明解释：** 如果学习者只练习但没有反馈，错误答案可能被反复强化；及时反馈能帮助修正理解。
   **例子或自测问题：** 为什么练习题最好配合答案反馈一起使用？
```

## 说明

本项目只提供 Skill 指令文件和 Codex 界面元数据，不包含额外脚本、网页服务或图形界面。实际知识卡片由 Codex 根据 `skills/make-knowledge-cards/SKILL.md` 中的规则生成。
